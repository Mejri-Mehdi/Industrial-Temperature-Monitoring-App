<h1 align="center">🏭 Industrial Motor Temperature Monitoring App 🚀</h1>

<p align="center">
  <strong>An Android application built with Kotlin for real‑time temperature monitoring of multiple motors and rooms in industrial environments.<br>Instant alerts, remote updates, and MySQL data logging keep you informed and your equipment safe.</strong>
</p>

---

## 🌟 Features

- 🌡️ **Real‑Time Temperature Monitoring** – continuous data collection from multiple motors and rooms  
- 🚨 **Instant Alerts** – push notifications when temperature thresholds are exceeded  
- 📡 **Remote Updates** – workers and managers stay informed from any distance  
- 🗄️ **Database Integration** – all sensor data stored in a MySQL database for analysis & reporting  
- 📱 **User‑Friendly Interface** – intuitive Android UI built with modern Kotlin  

---

## 📊 How It Works

1. **Sensors** attached to motors and rooms send temperature data.  
2. The **Android app** collects the data in real‑time.  
3. **Thresholds** are monitored automatically.  
4. If temperature limits are crossed, **alerts** are sent immediately to the user.  
5. All data is **logged in a MySQL database** for historical tracking and analysis.

## 🚀 Getting Started

### Prerequisites

- **Android Studio** (latest stable version recommended)
- **JDK 11** or higher
- A running **MySQL** server (local or remote)
- An Android device or emulator (API level 24+)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mejri-Mehdi/Industrial-Motor-Temperature-Monitoring.git
Open the project in Android Studio.

Sync Gradle and let the project build.

🧑‍💻 Usage
Open the app and grant required permissions (network, notifications).

The dashboard shows live temperature readings for all configured motors/rooms.

Thresholds can be adjusted from the settings screen.

Alerts appear as push notifications and are also logged in‑app.

✨ Future Improvements
Add user authentication (login for managers vs. workers)

Cloud synchronization with Firebase or REST API

Historical charts & graphs for trend analysis

Multi‑language support

Export data to PDF/CSV
