## 🌟 Core Features

- 🌡️ **Real‑Time Monitoring** – Continuous telemetry data acquisition from multiple industrial motor rooms and physical units.
- 🚨 **Instant Alerts** – Immediate push notifications and visual indicators triggered when temperature thresholds are exceeded.
- 📡 **On-Premise Server Logs** – Live synchronization with a local MySQL instance for reliable, closed-network data persistence.
- 📱 **Modern UI/UX** – Highly responsive and intuitive Material Design dashboard built using Kotlin and Android SDK.

---

## 📊 How It Works (Surface Level)

1. **Sensors** measure ambient and device temperature.
2. The **Android App** listens for data changes via standard local protocols.
3. **Thresholds** are checked locally inside the app.
4. **Alerts** are pushed instantly if safety limits are breached.
5. All logs are securely saved into the **MySQL Database** for future compliance checks.
